# Support

For reproducible bugs and focused feature requests, use the repository's GitHub
issue forms after checking existing issues.

Before posting:

- remove API keys and credentials;
- do not upload private source media, projects, history, or exported profiles;
- include the Sthang Studio version/commit and Windows version when relevant;
- describe a minimal reproduction using non-private sample content.

Security vulnerabilities must **not** be reported in a public issue. Follow
`SECURITY.md` instead.

General product information and Sthang contact options are available at
https://sthang.com/.
