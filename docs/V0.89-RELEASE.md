## Included behavior

- Project AI options offer Automatic, Gemini 3.8 Flash or Gemini 3.6 Flash.
  Explicit choices use only that model; persisted jobs retain their model pair
  through Resume. The choice preserves global settings and existing captions.
- Desktop Preview, Captions and Tool panels support direct header dragging,
  keyboard arrangement, neighboring-pane resizing and browser-local preferences.
  Reordering requires browser support for matching visual and keyboard reading
  order; other browsers retain the default order and working resizing. Smaller
  windows keep a preview-first scrolling layout.
- Fine timing uses a separate waveform dock. Appearance starts with essential
  controls and reveals additional controls on request. Comparison decisions remain
  accessible alongside save-recovery notices.
- Provider safety blocks have bounded explanations without raw provider content.

There is no new provider, telemetry category, third-party dependency or protected
artwork change. Fresh AI listens still make new requests.
