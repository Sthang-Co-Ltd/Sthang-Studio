# Sthang Studio 0.90.0 release evidence

The [0.90.0 Public Beta](https://github.com/Sthang-Co-Ltd/Sthang-Studio/releases/tag/v0.90.0)
provides recovery downloads and signed in-app updates for Windows 10/11 x64 and
Apple Silicon macOS 12.3+. Both live offers were verified on November 10, 2026
at 01:13 ICT. The recovery release was published at 01:12 ICT.

Release commit `b9bfed34b6296f370533550e768e8a7d924ee5b1`.
Source tree `514247c07393545e2c8298098675c9460f7db394`.
The `v0.90.0` tag resolves to that commit. The packages retain the README and
product manifest from that release commit.

## Included workflows

- Word highlighting syncs unresolved captions locally and saves usable timings.
  Review exceptions in Fine Timing or undo the timing changes.
- Fine Timing can suggest revised caption edges for short cues. Play the
  suggestion, apply it explicitly, then review the affected captions.
- Add optional Accuracy context before generation. Preview Find and Replace
  changes, and find preset feedback and previous exports in the export workspace.

Word sync and timing suggestions use local audio and wording. Generation still
sends the selected audio and relevant context to Gemini under the existing
processing disclosure.
