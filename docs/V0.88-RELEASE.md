# Sthang Studio 0.88 release preparation

Package version: `0.88.0`. Change ID:
`studio-v0-88-0-release-20261028`.

This record describes release preparation. The verified public baseline remains
`0.86.0` for Windows x64 and Apple Silicon macOS. A local build, draft GitHub
Release, staged package, or signature alone does not establish a live OTA offer.

## Included accepted changes

- Protect unfinished caption and Accuracy edits, retain recoverable browser
  drafts, and reject stale saves without overwriting newer saved work.
- Find saved projects with search, sorting and pages; surface unreadable or
  missing project storage with a safe recheck.
- Replace compatible footage while preserving reviewed captions and timing;
  require explicit acceptance for edited audio and retain recoverable evidence.
- Preview bulk corrections, repair export issues by caption, retain export
  choices during repairs, and distinguish historical outputs from current work.
- Improve native caption preview recovery and bounds handling, word timing,
  waveform navigation, dialog focus and deliberate playback seeks.

These changes are already accepted on the source baseline. This release
preparation changes release identity and evidence; it does not add another
provider, telemetry category, third-party dependency or protected artwork.
