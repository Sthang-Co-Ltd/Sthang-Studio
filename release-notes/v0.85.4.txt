Sthang Studio 0.85.4 - Public Beta

0.85.4 is the emergency Windows signed-OTA recovery that supersedes the broken 0.85.2 public OTA offer.
0.85.3 was production-signed as immutable evidence but was deliberately never promoted after unchanged v0.8.0 preparation still failed safely before activation.

Unchanged v0.8.0 brokers are supported through a narrowly bounded legacy preparation bridge that requires the exact broker markers and updates/work/.../source runtime location with repository tests absent.
Current OTA brokers explicitly request runtime-only TypeScript validation.
Curated/manual Windows setup also explicitly requests runtime-only TypeScript validation because runtime packages intentionally exclude repository tests.
Normal source npm run typecheck remains complete and still includes tests/tsconfig.json.
Runtime-only validation still checks packages/shared, apps/server, and apps/web before the production build.
Activated OTA runtimes repair npm's Windows workspace links after the broker moves the prepared tree into versions/0.85.4, keeping runtime imports bound to the immutable final version.

Signed package verification, fail-closed preparation, transactional activation, health checks, rollback, and stable user-state preservation remain unchanged.
Windows updates still require Download & verify followed by Install & restart; Studio never silently downloads or installs an update.

Curated recovery downloads support Windows 10 or 11 x64 and Apple Silicon macOS 12.3+.
The macOS package remains a manual-download recovery path and does not implement the Windows OTA updater.

0.85.4 otherwise preserves the accepted 0.85.x product and privacy behavior.
A Gemini Developer API key is still required for AI caption wording.
Studio requests store: false for Gemini interactions; normalized WAV audio is uploaded separately through the Gemini Files API and Studio does not explicitly delete that remote file.
Google currently documents Files API retention of up to 48 hours.
Khmer Caption Contributor and optional product analytics remain separate, off-by-default choices that require explicit opt-in.
