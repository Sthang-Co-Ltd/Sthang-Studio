Version {{VERSION}}

Accurate Khmer captions, ready for CapCut.

INSTALL
1. Extract the entire downloaded ZIP.
2. Double-click "Install Sthang Studio.bat".
3. Keep the setup window open while Studio prepares the required Windows tools and Khmer timing resources.
4. When setup finishes, launch Sthang Studio from the desktop shortcut.
5. In Studio, open Settings > AI connection and add your Gemini API key.

After installation completes, you can delete this extracted setup folder. Sthang Studio is installed into your Windows user profile and keeps its own app files there.

UPDATES
The verified public distribution and manual recovery path is the curated GitHub Release package.
The 0.8.0 bootstrap release includes the Studio public verification trust needed to verify later signed updates from updates.sthang.app.
That public key does not make OTA updates publicly available by itself. No public signed latest pointer is promoted as part of this GitHub Release.
Studio checks at most once per session plus a manual Check for updates action. It never continuously polls, never auto-downloads, and never auto-installs.
Download and installation each require explicit confirmation. Packages are verified and staged before activation, and failed setup, health checks, or interruption use rollback so the previous installed version and local caption data remain usable.
The curated GitHub Release remains the manual recovery path.

REQUIREMENTS
- Windows 10 or 11, x64
- Internet access during initial setup and AI transcription
- A Gemini Developer API key for AI caption wording
- Enough free disk space for local timing resources and your media

PRIVACY
When you generate or regenerate AI wording, Studio sends normalized WAV audio and relevant context or wording to Gemini using your API key.
Studio requests store:false for the interaction, uploads the WAV through the Gemini Files API, and does not explicitly delete that remote file.
Google currently documents that Files API uploads are stored for up to 48 hours.
Update checks disclose only the installed version/channel plus ordinary HTTPS metadata; they do not send projects, captions, media, Gemini keys, or device/license enrollment data.

Version 0.8.0 includes two separate privacy choices that stay off unless you turn them on in Settings > Privacy.
- Khmer Caption Contributor can share eligible corrections made after you join: only a bounded short audio clip around the corrected caption plus generated/corrected wording, timing, and technical evidence. Full videos, project names, filenames, API keys, unrelated captions, and analytics ids are excluded.
- Optional product analytics can send only allow-listed workflow events and coarse technical buckets through a Sthang-owned analytics relay using a random analytics installation id. Studio includes no session replay or autocapture and does not send caption/media content to analytics.

Contributor uploads are submitted first and are shown as verified only after corpus quality review accepts them. Unverified submissions expire after 180 days. Settings > Privacy provides a Request deletion action for contribution data already sent to Sthang; local projects are not deleted by that request.

See PRIVACY.md inside "Sthang Studio Files", docs/KHMER-CAPTION-CONTRIBUTOR.md in the public source repository, and https://ai.google.dev/gemini-api/docs/files.

The "Sthang Studio Files" folder is used automatically by setup. You do not need to open or edit anything inside it.

Privacy, license, and third-party notices are included with the installed application and are also available in the Sthang Studio source repository.
