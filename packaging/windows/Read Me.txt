STHANG STUDIO FOR WINDOWS
Version {{VERSION}}

Accurate Khmer captions, ready for CapCut.

INSTALL
1. Extract the entire downloaded ZIP.
2. Double-click "Install Sthang Studio.bat".
3. Keep the setup window open while Studio prepares the required Windows tools and Khmer timing resources.
4. When setup finishes, launch Sthang Studio from the desktop shortcut.
5. In Studio, open Settings > AI connection and add your Gemini API key.

After installation completes, you can delete this extracted setup folder. Sthang Studio is installed into your Windows user profile and keeps its own app files there.

UPDATES
The verified public distribution and manual recovery path is the curated GitHub Release package.
This source package may contain an unreleased signed-updater architecture for updates.sthang.app, but it is not evidence that OTA updates are publicly available.
When a future signed updater is deliberately provisioned and released, Studio will check at most once per session plus a manual action and will require explicit confirmation before download and installation.
Failed checks or rollback leave the installed version and local caption data usable.

REQUIREMENTS
- Windows 10 or 11, x64
- Internet access during initial setup and AI transcription
- A Gemini Developer API key for AI caption wording
- Enough free disk space for local timing resources and your media

PRIVACY
When you generate or regenerate AI wording, Studio sends normalized WAV audio and relevant context or wording to Gemini using your API key.
Studio requests store:false for the interaction, uploads the WAV through the Gemini Files API, and does not explicitly delete that remote file.
Google currently documents that Files API uploads are stored for up to 48 hours.
See PRIVACY.md inside "Sthang Studio Files" and https://ai.google.dev/gemini-api/docs/files.

The "Sthang Studio Files" folder is used automatically by setup. You do not need to open or edit anything inside it.
